chocolatebox 분기 테마 시스템 가이드

브랜드는 그대로 두고, 분기마다 색·이미지·구조 프리셋·문구만 설정 한 블록으로 바꾸는 방법을 정리했습니다. 앱테크·마이페이지·박스 상세·합성존·내보관함 5개 화면 기준입니다.

1. 4개 레이어

한 분기 = 설정 블록 1개 + 이미지 몇 장. 아래 순서대로 바꾸는 범위가 넓어지고 위험도도 올라갑니다.

고정브랜드노란 상단바, 검정 CTA, 하단 탭, 서체, 모서리·간격 규칙. 어떤 분기에도 바꾸지 않습니다.
교체시즌 토큰강조색, 파스텔 4세트, 배너·히어로 색 등. 분기마다 값만 바꿉니다.
교체이미지 슬롯배너·선물상자·3D 아이콘·게임 일러스트. 파일만 교체하고 코드는 그대로입니다.
선택구조 프리셋게임 카드·보관함·바로가기·탭 표시 방식을 프리셋에서 고릅니다. 분기당 1~2개만 권장합니다.

6. 구조 프리셋

색과 별개로 구조를 바꿀 수 있습니다. 표의 ● 는 Q4(기본)와 다른 값입니다. 이번 설정의 변경 수: Q1 1개 · Q2 2개 · Q3 2개 · Q4 0개.

프리셋은 HTML을 바꾸지 않고 data-games 같은 속성 값으로만 전환됩니다. 새 프리셋은 CSS 블록 하나로 추가합니다.

7. 규칙

이렇게 합니다
  • 새 분기는 직전 분기 블록을 복사해서 시작합니다.
  • 강조색 hue는 분기당 1개. 나머지는 중립색과 파스텔로 받칩니다.
  • 값을 바꾸면 4번 대비 표부터 다시 확인합니다.
  • 구조 프리셋 변경은 분기당 1~2개로 제한합니다.
  • 이미지에는 대체 텍스트를 달고, 글자는 이미지에 굽지 않습니다.
  • 선택 토큰을 비우면 기본값으로 폴백됨을 확인합니다.
이렇게 하지 않습니다
  • 노란 상단바·검정 CTA·하단 탭 순서를 바꾸지 않습니다.
  • 한 화면에 시즌 강조색을 2개 이상 쓰지 않습니다.
  • 분기 시작 당일에 에셋을 처음 교체하지 않습니다.
  • 채도가 높은 색으로 화면 전체를 칠하지 않습니다.
  • 색만으로 의미를 구분하지 않습니다(명도·아이콘도 다르게).
  • 미출시 테마가 노출되는 ?theme= 를 운영에서 열어 두지 않습니다.

8. 분기 운영

  1. D-30 · 시즌 브리프컬러 방향, 모티프, 대표 이벤트명을 정합니다. (기획·디자인)
  2. D-21 · 에셋 제작5번 슬롯 표 기준으로 이미지를 제작합니다. (디자인)
  3. D-10 · 설정 작성직전 분기 블록을 복사해 토큰·프리셋·문구를 채우고 에셋을 올립니다. (디자인·개발)
  4. D-7 · 프리뷰 QA내부 빌드에서 ?theme= 로 5개 화면을 확인합니다. 9번 체크리스트를 사용합니다. (QA)
  5. D-3 · 승인대비 표와 스크린샷으로 최종 승인을 받습니다. (기획)
  6. D-day 0시(KST) · 자동 전환날짜 기준으로 새 분기 블록이 적용됩니다.
  7. D+7 · 점검과 롤백이상이 있으면 원격 설정으로 직전 분기를 고정합니다. 문제 없으면 종료합니다.

9. QA 체크리스트

  • 5개 화면 모두 새 분기 색으로 보인다
  • 상단바·검정 CTA·하단 탭이 그대로다
  • 4번 대비 표가 모두 ✓ 이다
  • 360px 폭에서 가로 스크롤이 생기지 않는다
  • 배너 문구가 길어도 두 줄 안에 들어간다
  • 이미지가 없을 때 기본(Q4) 이미지로 대체된다
  • 선택 토큰을 비운 분기에서도 깨지지 않는다
  • 하단 탭 활성 표시가 색 외에도 구분된다
  • iOS Safari · Android Chrome에서 확인했다
  • 분기 경계(31일 → 1일 0시)에 전환된다

10. 개발 적용

분기 1개는 설정 JSON 블록 1개입니다. 토큰은 CSS 변수로, 구조는 data-* 속성으로 적용합니다.

{
  "q4": {
    "tokens": {
      "header-bg": "#FFD000",
      "accent": "#D8343F",
      "banner-a": "#F9D869",
      "...": "..."
    },
    "pastels": [
      {
        "bg": "#FFF6DC",
        "ink": "#8F6200",
        "btn": "#F5C971",
        "btnInk": "#3A2A00"
      },
      "..."
    ],
    "layout": {
      "games": "grid",
      "vault": "list",
      "shortcuts": "circles",
      "nav": "pill"
    },
    "banner": {
      "kicker": "10월 4주차 스페셜이벤트!!",
      "title": "초코랭킹"
    }
  }
}

선택 순서

  1. ?theme=q1 (내부·스테이징만)미출시 분기를 미리 봅니다. 데모는 이 방식을 열어 두었습니다.
  2. 원격 설정 오버라이드롤백이나 긴급 고정용입니다. 데모에는 구현하지 않았습니다.
  3. KST 날짜분기 시작일 0시에 자동 전환합니다. 데모에 구현되어 있습니다.

적용 계약

<html data-theme="q4">                       토큰: :root { --accent: #D8343F; ... }
<div class="app" data-games="grid" ...>      구조: [data-games="rail"] .games { ... }
  data-games · data-vault · data-shortcuts · data-nav

데모(index.html)는 전달받은 스크린샷을 기준으로 다시 그린 것이며, 이미지·로고·서체는 대체물입니다. 이 가이드의 표는 데모의 분기 설정 JSON에서 생성했습니다.
