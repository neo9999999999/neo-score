# 5일선 돌파/상단 스크리너 (익절 +14% / 매수봉 저가이탈 손절)

HTS 조건검색식(A~M)을 코드로 옮긴 스크리너 + 커스텀 청산 백테스트입니다.
`scripts/screen-ma5-breakout.mjs`.

## 조건 조합 (사용자 요청)

```
( H "5일선 돌파(골든크로스)"  OR  J "5일선 위" )
AND  A · B · C · D · E · F · G · I · K · L
```

> M(전일 종가<MA5)은 5일선 조건을 "돌파 or 위"로 정의(H||J)하면서 AND에서 제외했습니다.
> M은 골든크로스 H("전일 종가≤MA5 && 당일 종가>MA5")에 이미 포함돼 있어, AND로 강제하면
> "이미 5일선 위(J)" 케이스가 잡히지 않기 때문입니다.

| 코드 | HTS 문구 | 코드 구현 |
|---|---|---|
| A | 주가범위: 종가 1,000 ~ 99,990,000 | `close ∈ [1000, 99990000]` |
| B | 주가등락률: 당일 종가등락률 7%~28% | `7 ≤ 등락률 ≤ 28` |
| C | 거래대금 5,000(백만)↑ | `종가×거래량 ≥ 50억` |
| D | 기간내 등락률: 1~10봉전 중 일간등락 20%↑ 1회 | 최근 10봉 내 20%↑ 존재 |
| E | 기간내 거래대금: 1~10봉전 (스크린샷 값 잘림) | 최근 10봉 내 거래대금 ≥ 50억 존재 **(가정)** |
| F | 기간내 거래량비율: 0~10봉 전봉대비 300%↑ 1회 | 최근 10봉 내 전봉거래량×3 돌파 존재 |
| G | 거래량비율(n봉): 당일/전일 100%↑ | `당일거래량 ≥ 전일거래량` |
| H | 주가이평돌파: (종가1) (종가5) 골든크로스 | `전일 종가 ≤ 전일MA5 && 당일 종가 > MA5` |
| I | 주가이평비교: (종가5) > (종가20) | `MA5 > MA20` |
| J | 주가이평비교: (종가1) > (종가5) | `종가 > MA5` |
| K | 주가비교: 시가 < 종가 | `open < close` (양봉) |
| L | 최고종가: 종가가 4봉중 최고종가 | `close ≥ max(직전 3봉 종가)` |
| M | 주가이평비교: 1봉전 (종가1) < (종가5) | AND에서 제외 (위 설명 참고) |

## 청산 규칙 (사용자 지정)

- **진입** = 신호(매수)봉 **종가** (이 리포지토리 전체 백테스트 관례와 동일)
- **익절** = 진입 후 장중 고가가 **+14%** 도달 시 그 가격 (`TP` 환경변수로 조정)
- **손절** = 진입 후 장중 저가가 **매수봉 저가**를 이탈하면 그 가격
- 보수적 가정: 같은 날 익절가·손절가 동시 터치 시 **손절 우선**
- 시가가 이미 매수봉 저가 이하로 갭하락하면 시가 청산(`SL_GAP`)
- 최대 `MAX_HOLD`(기본 20) 거래일 초과 시 종가 청산(`TO`)
- 왕복 거래비용 `COST`(기본 0.6%) 차감

## 실행

> ⚠ 야후 파이낸스에서 일봉 OHLCV를 받으므로 **시세 egress가 허용된 환경**
> (로컬/깃허브 액션)에서 실행하세요. Claude Code 웹 세션은 시세 호스트가
> 차단되어 있어 이 스크립트를 돌릴 수 없습니다.

```bash
node scripts/screen-ma5-breakout.mjs                 # 2026년, 익절 14%
YEAR=2025 TP=14 MAX_HOLD=20 node scripts/screen-ma5-breakout.mjs
node scripts/screen-ma5-breakout.mjs --selftest      # 시세 없이 로직만 검증
```

결과는 콘솔 요약 + `data/screen-ma5-breakout-<YEAR>.json`(추출 신호 전체 + 통계)으로 저장됩니다.

### 조정 가능한 환경변수

| 변수 | 기본 | 의미 |
|---|---|---|
| `YEAR` | 2026 | 백테스트 대상 연도 |
| `TP` | 14 | 익절 % |
| `MAX_HOLD` | 20 | 최대 보유 거래일 |
| `COST` | 0.6 | 왕복 거래비용 % |
| `UNIVERSE` | 2000 | 시총 상위 N 유니버스(`data/stocks.json`) |
| `CHG_MIN`/`CHG_MAX` | 7/28 | B 등락률 구간 |
| `VALUE_MIN` | 5e9 | C·E 거래대금 하한(원) |
| `VOL_SURGE` | 3 | F 전봉거래량 배수 |
| `D_CHG` | 20 | D 기간내 일간등락 하한 |

## 확정된 규칙

1. **진입 시점** — 신호봉 **종가** 진입.
2. **E 조건** — 최근 10봉 내 거래대금 **50억 이상** 1회.
3. **5일선 조건** — **돌파(H) 또는 위(J)**. M은 AND에서 제외.
