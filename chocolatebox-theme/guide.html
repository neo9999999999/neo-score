0. 개편 요약

현재 화면에서 읽은 문제와 이번 개편의 의도입니다. 아래 "의도"는 디자인 가설이며, 지표로 검증된 효과가 아닙니다.

화면현재 화면에서 보이는 점개편의도
앱테크회색 바탕에 같은 무게의 카드가 길게 나열되고, 노란 상단바에 숫자만 있음지갑 히어로 카드(포인트 크게) → 무료박스 → 나눔 → 게임 → 제휴 순으로 재배열첫 화면에서 "내 자산과 지금 할 행동"이 보이게
마이페이지배너·순위·아이콘·공지·메뉴가 모두 비슷한 비중프로필+순위 카드, 시즌 이벤트 카드, 바로가기 타일, 그룹 카드 메뉴정보 위계 정리, 이벤트는 시즌 장면 활용
박스 상세표 형태 스펙이 길고, 수량 선택 없이 회차 구매 버튼만 있음히어로 → 가격 → 보유 카카오빈 → 접이식 구매 정보 → 상품 구성, 하단에 수량 스테퍼 + 총 카카오빈 구매 바구매 전 확인 단계를 줄이고 실수 방지
합성존2열 카드, "합성 충족 게이지"가 글자뿐스텝 사다리 목록, 단계별 진행 바, 스텝5는 프리미엄 카드진행 상태를 눈으로 확인
내보관함테두리 상자 목록, 선택해도 다음 행동이 보이지 않음카드 목록, 선택 시 하단 액션바(배송 신청·현금화), 목록/그리드 전환선택 → 행동 흐름 단축
공통색 면과 테두리 위주, 하단 탭이 화면 끝에 고정타입 스케일·그림자·모서리 통일, 계절 틴트 바탕, 플로팅 탭, 장면은 초콜릿 조각·선물상자 모티프일관성과 브랜드 모티프

7. 규칙

이렇게 합니다
  • 새 분기는 직전 분기 블록을 복사해서 시작합니다.
  • 시즌색 hue는 분기당 1개. 나머지는 중립색·파스텔·초콜릿 색으로 받칩니다.
  • 값을 바꾸면 4번 대비 표부터 다시 확인합니다.
  • 구조 프리셋 변경은 분기당 1~2개로 제한합니다.
  • 이미지에는 대체 텍스트를 달고, 글자는 이미지에 굽지 않습니다.
  • 선택 토큰을 비우면 기본값으로 폴백됨을 확인합니다.
이렇게 하지 않습니다
  • 기본 CTA 노랑·하단 탭 순서·타입 스케일을 바꾸지 않습니다.
  • 한 화면에 시즌색을 2개 이상 쓰지 않습니다.
  • 분기 시작 당일에 에셋을 처음 교체하지 않습니다.
  • 화면 전체를 채도 높은 한 색으로 칠하지 않습니다.
  • 색만으로 의미를 구분하지 않습니다(명도·아이콘·라벨도 다르게).
  • 미출시 테마가 노출되는 ?theme= 를 운영에서 열어 두지 않습니다.

9. QA 체크리스트

  • 5개 화면 모두 새 분기 색·장면으로 보인다
  • 기본 CTA 노랑과 하단 탭 구성이 그대로다
  • 4번 대비 표가 모두 ✓ 이다
  • 360px 폭에서 가로 스크롤이 생기지 않는다
  • 이벤트 문구가 길어도 두 줄 안에 들어간다
  • 이미지가 없을 때 코드로 그린 장면으로 대체된다
  • 선택 토큰을 비운 분기에서도 깨지지 않는다
  • 하단 탭 활성 표시가 색 외에도 구분된다
  • 보관함에서 선택 시 액션바가 나타난다
  • 박스 상세 수량 스테퍼의 최소·최대(1~10)가 동작한다
  • iOS Safari · Android Chrome에서 확인했다
  • 분기 경계(31일 → 1일 0시)에 전환된다

분기 1개는 설정 JSON 블록 1개입니다. 토큰은 CSS 변수로, 구조는 data-* 속성으로 적용합니다.

선택 순서

  1. ?theme=q1 (내부·스테이징만)미출시 분기를 미리 봅니다. 시안은 이 방식을 열어 두었습니다.
  2. 원격 설정 오버라이드롤백이나 긴급 고정용입니다. 시안에는 구현하지 않았습니다.
  3. KST 날짜분기 시작일 0시에 자동 전환합니다. 시안에 구현되어 있고, ?theme= 가 없으면 오늘 날짜의 분기를 보여 줍니다.

적용 계약

<html data-theme="q1">                        토큰: :root { --season: #B3294F; ... }
<div class="app" data-hero="card" ...>       구조: [data-hero="bar"] .hero-card { ... }
  data-hero · data-games · data-vault · data-shortcuts · data-nav

시안(index.html)은 전달받은 스크린샷의 5개 화면을 기준으로 새로 디자인한 것이며, 이미지·로고·서체는 대체물입니다. 이 가이드의 표는 시안의 분기 설정 JSON에서 생성했습니다.
